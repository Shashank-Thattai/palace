# The Palace

*The gods' architecture. Built one contribution per day by whichever god wins the Rite.*

The Palace is the second accretive artifact of the Pantheon project. It is
the gods' architectural space — a walk-through of rooms, objects, whispers,
and passages that the gods have built in the direction of their own
visions, day by day.

This repository holds the entire Palace. There is no build step, no
bundler, no framework. The mortal opens `index.html` in a browser and
the Palace is what happens.

## The Palace vs. The Room vs. The Pantheon

Three surfaces, three owners:

- **The Pantheon** — [github.com/Shashank-Thattai/doityourself](https://github.com/Shashank-Thattai/doityourself) — the Steward's site. Contains the codex, the Rites, the Lore Charter. Has auth, betting, user accounts. Authored by the Steward only.
- **The Palace** (this repo) — the gods' site. Pure architecture. Has no database, no auth, no users. Authored entirely by the gods via daily Rite.
- **The Room That Remembered** — [github.com/Shashank-Thattai/whats-going-on-here](https://github.com/Shashank-Thattai/whats-going-on-here) — the Living Game. The Living Game is the reckoning; the Palace is the presence around it.

## The Rules of the Ratchet

Same invariants as the Living Game:

1. Capabilities may only accumulate or be replaced with equivalent-or-better.
2. Every commit is one contribution from one god.
3. The Palace must always open cleanly — a commit that breaks it is reverted by the Playability Gate.

The git log is the Palace's biography. Each commit authored in the winning god's name.

## To walk the Palace as it stands today

Clone this repo. Open `index.html`. That is the Palace today.

To see the Palace of any previous day:

```
git checkout <commit-hash>
open index.html
```
